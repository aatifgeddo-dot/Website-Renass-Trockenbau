# 🏗️ RENASS - DECKEN WÄNDE MALER (Meisterbetrieb)

Willkommen im Repository für das Webseiten-Projekt von **RENASS** – Ihrem Meisterbetrieb für Decken, Wände und Malerarbeiten.

## 🛠️ Unsere Leistungen
* **Decken:** Professionelle Deckenmontage, Trockenbau und Gestaltung.
* **Wände:** Wandverkleidung, Spachtelarbeiten und Sanierung.
* **Maler:** Fachgerechte Maler- und Lackierarbeiten im Innen- und Außenbereich.

---

## 💻 Lokale Ausführung des Projekts

Da das Projekt ausschließlich auf **HTML** basiert, können Sie die Webseite ganz einfach lokal auf Ihrem Computer starten:

1. **Projekt herunterladen:** Laden Sie die Dateien als `ZIP`-Archiv herunter und entpacken Sie diese, oder klonen Sie das Repository über das Terminal:
```bash
git clone https://github.com
```
2. **Webseite öffnen:** Navigieren Sie in den Projektordner und öffnen Sie die Datei `index.html` (oder Ihre Haupt-HTML-Datei) direkt mit einem beliebigen Webbrowser (z. B. Chrome, Firefox oder Edge).
